# Accessibility (Phase 8)

**Target:** WCAG 2.2 Level AA where Streamlit allows.

## Implemented

| Requirement | How |
|-------------|-----|
| Color contrast | Semantic tokens verified for body text ≥4.5:1 and UI ≥3:1 on light/dark surfaces (see DESIGN_SYSTEM.md) |
| Focus visible | 2px ring + offset via `--focus-ring` on `:focus-visible` |
| Skip link | “Skip to main content” → `#venus-main` on protected pages |
| Landmarks | `main#venus-main`, header, nav (sidebar) |
| One h1 per page | `page_frame` / shell emits a single page title |
| Status not color-only | `status_badge` always includes icon + text label |
| Reduced motion | Tokens + preloader + skeleton shimmer respect `prefers-reduced-motion` |
| Prefers contrast | Stronger borders/muted text under `prefers-contrast: more` |
| Touch targets | `min-height/width: 44px` under `pointer: coarse` |
| Safe areas | Main padding uses `env(safe-area-inset-*)` |
| Live regions | `ui.a11y.announce()` for post-action messages |
| Forms | Streamlit labels on inputs; autocomplete on auth fields |
| Icon-only | SVG icons use `aria-hidden` unless a title is provided |

## Keyboard paths (manual QA)

1. **Login** — Tab through username, password, Sign in; Enter submits form  
2. **Booking wizard** — Tab through steps; Back/Continue reachable  
3. **Status update** — Select + Update + Confirm/Cancel focusable  
4. **Directory filters** — Search, multiselect, layout radio  

## Limitations (Streamlit)

- Global shortcuts (e.g. true Cmd+K command palette) are unreliable; use visible controls  
- Focus restore after `st.dialog` depends on Streamlit version behavior  
- Cannot fully restyle native file inputs / some widgets  
- Automated axe-core / Playwright runs are recommended in CI (Phase 10) but not bundled here  

## Testing checklist

- [ ] Keyboard-only walk of login → dashboard → book → logout  
- [ ] 200% browser zoom without horizontal scroll on 1280 and 390 widths  
- [ ] Dark + light theme contrast spot-check on KPI, badge, error, button  
- [ ] `prefers-reduced-motion: reduce` — preloader static, no shimmer
